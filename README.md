## 🔄 Git Workflow

We follow a simple Git workflow for team development.

**1. Feature Branches**
- Each team member works on their assigned task.
- Completed work is pushed to GitHub.

**2. DEV Branch**
- All team members merge their work into `dev`.
- We test and fix issues in this branch.

**3. MAIN Branch**
- After testing, we create a Pull Request from `dev` to `main`.
- Once approved, changes are merged into `main`.

**4. Live Website**
- GitHub Pages deploys the website from `main`.

### Development Flow

```text
Feature Branches
       ↓
    DEV Branch
       ↓
 Testing & Review
       ↓
    MAIN Branch
       ↓
  GitHub Pages
       ↓
   Live Website
```
